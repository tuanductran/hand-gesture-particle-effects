# Hand Gesture Particle Effects

An interactive browser experiment that uses your webcam to detect hand gestures and trigger cinematic particle effects in real time.

## Features

- **Open Palm** → layered firework bloom with falling embers
- **Index Finger** → precise comet-like particle trail
- **Fist** → magical shockwave pulse from the palm
- Built with **MediaPipe Hands**, **HTML5 Canvas**, and lightweight client-side JavaScript
- No build step required — open directly in a modern browser

## How to Run

1. Open the deployed page or download the repo
2. Allow camera access when prompted
3. Try these gestures in front of your webcam:
   - ✋ Open Palm
   - ☝️ Index Finger
   - ✊ Fist

## Tech Stack

- HTML
- CSS
- JavaScript
- MediaPipe Hands
- HTML5 Canvas

## Notes

For best results, use good lighting and keep one hand clearly visible to the camera.
